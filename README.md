# CIRCULATION Practice Web Prototype

ボードゲーム **「CIRCULATION -North America-」**
を個人で練習・ルール確認する目的で制作した、非公式のブラウザ用プロトタイプです。

> **IMPORTANT:** このリポジトリは **CIRCULATION
> の公式デジタル版ではありません**。原作者・権利者・販売元による承認、提携、監修を受けたものではありません。

## 原作について

「CIRCULATION」は、彫刻家 **瀬戸優（Yu Seto）氏**
が構想・デザインした、食物連鎖と自然界の循環をテーマとするボードゲームです。

-   公式販売ページ: https://ettone.official.ec/items/79781751
-   CAMPFIRE 制作プロジェクト: https://camp-fire.jp/projects/688496/view

## このプロジェクトの目的

このHTML版は、所有している実物ゲームのルール確認・一人での練習・プログラミング学習を目的として制作しています。

原作のゲームシステム、カード構成、資源、捕食、繁殖、分解者、自然現象などを参考にしており、原作ルールを強く再現した内容を含みます。

追加・変更している主な要素には、ブラウザ操作用UI、スマートフォン表示、BOT対戦処理、自動処理、ログ表示などがあります。

## 起動方法

1.  HTMLファイルを保存します。
2.  Chrome、Edge、Firefox、Safari等のブラウザでHTMLファイルを開きます。
3.  `NEW GAME` からゲームを開始します。

特別なインストールは必要なく、基本的にHTML単体で動作します。
